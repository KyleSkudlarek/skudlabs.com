

Overall Timeline to First Client

Goal: Secure your first client ($4,000 project) within 6–8 weeks.

Detailed Breakdown

Day 0–7: Foundation Setup
	1.	File for LLC (1–3 Days)
	•	Action: File the Certificate of Formation through Texas SOS Direct.
	•	Time: Immediate if done online, approval within 1–3 business days.
	•	Cost: $300 filing fee.
	•	Parallel Task:
	•	Start drafting client contract language (use Rocket Lawyer or LawDepot for templates).
	2.	Obtain EIN (1 Day)
	•	Action: Apply for free via the IRS website.
	•	Time: Instant approval online.
	•	Cost: Free.
	•	Parallel Task:
	•	Research banks for business accounts.
	3.	Open Business Bank Account (1–3 Days)
	•	Action: Visit a bank (e.g., Chase, Bluevine) with LLC and EIN documents.
	•	Time: Account setup is usually same-day.
	•	Cost: Free to open, but watch for minimum balance requirements.

Day 8–14: Wireframe and Asset Creation
	1.	Learn Figma Basics (1–2 Days)
	•	Action: Follow free Figma tutorials on YouTube or Figma’s site.
	•	Time: Dedicate 3–5 hours.
	•	Cost: Free.
	2.	Create Mobile Wireframe (2–3 Days)
	•	Action: Design a low-fidelity mobile-first wireframe for the homepage.
	•	Time: ~2–3 days if learning as you go.
	•	Parallel Task:
	•	Start brainstorming SVG design ideas for logos and mockups.
	3.	Develop SVG Assets and Finalize Wireframe (3 Days)
	•	Action: Create your logo, background patterns, device mockups, etc.
	•	Time: Use tools like Figma or Canva for quick asset creation.
	•	Cost: Free (or Canva Pro ~$12/month).

Day 15–28: Build and Launch Website
	1.	Code Website (7–10 Days)
	•	Action:
	•	Use your wireframe to code a mobile-first website with HTML/CSS.
	•	Leverage frameworks like Bootstrap or TailwindCSS to speed up the process.
	•	Time: 7–10 days depending on complexity.
	•	Tools: Use Visual Studio Code or a similar IDE, and deploy on Netlify (free).
	•	Parallel Tasks:
	•	Finalize your client contract.
	•	Start creating a list of small businesses for cold outreach.
	2.	Optimize for Desktop (3–5 Days)
	•	Action: Scale your website design for larger breakpoints (tablet and desktop).
	•	Time: 3–5 days.
	•	Parallel Task: Test your website for performance using Google Lighthouse.

Day 29–42: Marketing and Outreach
	1.	Set Up Basic Marketing (3 Days)
	•	Action:
	•	Create a LinkedIn profile highlighting your business.
	•	Design a simple Google Ads campaign targeting “small business web design” in your local area.
	•	Write 3–5 cold email templates.
	•	Time: 3 days.
	•	Budget: Start with $10–$20/day for Google Ads (~$300 for the first month).
	2.	Cold Outreach (14 Days Ongoing)
	•	Action:
	•	Email 100+ local small businesses (e.g., gyms, restaurants, salons).
	•	Follow up with calls or LinkedIn messages.
	•	Goal: Secure your first $4,000 client.
	•	Time Commitment: ~2 hours/day for outreach.
